# Code of Conduct

ModelQuad adopts the **Contributor Covenant, version 2.1**, as its code of
conduct. The full text is at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It applies in every project space: issues, pull requests, discussions,
reviews and commit messages. It also applies when someone represents the
project elsewhere.

In short: be respectful and patient, assume good intent, keep criticism about
the work and not the person, and do not harass anyone.

## Reporting

If someone's behaviour concerns you, report it privately:

- through GitHub's private reporting on this repository (the **Security**
  tab, **Report a vulnerability**), with "Code of conduct" in the title; or
- by e-mail to support@modelquad.com, with "Code of conduct" in the subject.

Please do not report conduct problems in a public issue.

Reports are kept confidential. The maintainer reviews each report and
decides on a response, following the enforcement guidelines in the
Contributor Covenant.
